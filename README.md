# VirtualChest

Плагин для Minecraft сервера, добавляющий виртуальные сундуки для хранения предметов.

## 🎯 Возможности

- **Личный виртуальный сундук** для каждого игрока
- **27 слотов** хранилища
- **Сохранение предметов** между входами на сервер
- Поддержка **алиасов команд**

## 📋 Требования

- Minecraft Server 1.21+
- Java 11+
- Maven 3.6+

## 🚀 Установка

1. Скомпилируйте проект:
```bash
mvn clean package
```

2. Скопируйте JAR файл из папки `target/` в папку `plugins/` вашего сервера

3. Перезагрузите сервер:
```
/reload confirm
```

## 💬 Команды

| Команда | Описание | Разрешение |
|---------|---------|-----------|
| `/virtualchest` | Открыть виртуальный сундук | `virtualchest.use` |
| `/vc` | Алиас команды `/virtualchest` | `virtualchest.use` |
| `/virtualchest help` | Показать справку | `virtualchest.use` |

## 🔐 Разрешения

- `virtualchest.use` - Разрешение для использования команды

## 🔧 Использование

1. Введите команду `/virtualchest` в чат
2. Откроется окно сундука на 27 слотов
3. Разместите предметы в сундуке
4. Закройте сундук — предметы сохранятся
5. При следующем входе все предметы будут на месте

## 🐛 Сообщение об ошибках

Если при вводе команды видите ошибку, проверьте:
- Есть ли у вас разрешение `virtualchest.use`
- Правильно ли написана команда
